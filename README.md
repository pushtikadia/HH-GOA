## 🌺 Project Overview

**HH Goa 2026 — Builder ID Generator** is an interactive web application designed to create a personalized digital Builder ID card for **Hacker House Goa 2026**.

The application combines a modern hacker/builder aesthetic with a distinctly **Goan visual identity**. Users can upload their photograph, enter their personal event details, adjust their photo positioning, preview the final card in real time, and download the generated Builder ID as a high-resolution PNG.

The project is intentionally lightweight and runs entirely in the browser.
