## Overview

**HH Goa 2026 — Builder ID Generator** is a lightweight, browser-based
application that allows builders to create a personalized digital identity
for Hacker House Goa.

The project brings together a modern builder-focused experience with a
visual language inspired by **Goa's coastline, tropical greenery, beaches,
sunlight, heritage architecture, and vibrant culture**.

Users can upload their photograph, customize their **name, date, and
location**, adjust their profile image, preview the Builder ID in real time,
and export the final result as a high-resolution image.

The entire experience runs directly in the browser and requires:

- No backend
- No database
- No authentication
- No account
- No installation
