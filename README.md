## 🌺 About the Project

**HH Goa 2026 — Builder ID Generator** is a modern, browser-based web application designed to create personalized Builder ID cards.

The project combines a **Goan tropical aesthetic** with a modern **hacker and builder culture**, creating a visual experience inspired by Goa's beaches, greenery, heritage architecture, sunshine, and vibrant atmosphere.

Users can upload their photo, enter their personal details, adjust their photo position, preview the Builder ID in real time, and download the final design as a high-resolution PNG.

The entire application runs directly in the browser and does not require a backend or database.

## ✨ Features

### 👤 Personal Information

Customize your Builder ID using:

- Name
- Date
- Location

The ID card updates automatically whenever you change the information.

### 📸 Photo Upload

Upload your own profile photo and customize its appearance.

Supported formats include:

- JPG / JPEG
- PNG
- WebP
- HEIC / HEIF*

You can also:

- Zoom your photo
- Drag and reposition your photo
- Automatically crop it into the circular profile area

> *HEIC/HEIF support depends on browser compatibility.*
